Tentang Brando Windah

Brando Windah (lahir 14 Maret 1992) adalah seorang YouTuber, streamer, dan kreator konten asal Manado, Indonesia. Dikenal dengan sebutan "Papa Brando" atau "Lord Windah", beliau disukai oleh jutaan penonton karena gaya streaming-nya yang sangat menghibur, penuh drama teatrikal unik, serta kebaikan hatinya dalam beramal.

Dampak Sosial & Charity

Windah Basudara terkenal sering menggelar Charity Livestream selama berjam-jam tanpa henti untuk membantu anak-anak yang membutuhkan pendidikan, korban bencana alam, hingga panti asuhan di seluruh pelosok Nusantara.

1. Ide dan Tujuan Website

Judul Project: Website Portofolio & Fanpage Windah Basudara

Deskripsi Ide: Website ini dibangun sebagai bentuk apresiasi kepada figur idola masyarakat Indonesia, yaitu Brando Windah (Windah Basudara). Website menyajikan biografi, statistik pencapaian, highlight streaming game, serta interaktif soundboard fan zone.

Tujuan Pembuatan Website:

  • Memenuhi Tugas Mata Pelajaran Informatika bab Pengembangan Web & Version Control.
  • Menerapkan pemahaman dasar HTML5 struktur semantic dan CSS Native styling.
  • Melatih alur kerja profesional developer menggunakan Visual Studio Code, Git CLI, dan remote repository GitHub.
  • Mempublikasikan karya web secara global secara gratis menggunakan GitHub Pages.

2. Struktur Folder & Kode (HTML & CSS External)

Sesuai dengan praktek wajib, seluruh aset dan kode disusun secara terstruktur di folder project komputer:

website-windah-basudara/ ├── assets/ │ ├── images/ │ │ ├── windah-avatar.jpg │ │ ├── banner.jpg │ │ └── game-thumbs/ │ └── audio/ │ └── meme-sounds/ ├── css/ │ └── style.css <-- CSS Native External ├── index.html <-- Halaman Utama (Beranda & Profil) ├── about.html <-- Halaman Detail Biografi terpisah ├── games.html <-- Halaman Daftar Game terpisah └── README.md <-- Dokumentasi Project GitHub

Aturan Penyusunan Link Menu File HTML Terpisah:

Menu navigasi saling terhubung menggunakan tag anchor <a href="..."> ke halaman HTML terpisah dan menghubungkan CSS External menggunakan tag <link rel="stylesheet" href="css/style.css"> di dalam tag <head>.

3. Proses Membuat Repository & Menghubungkan Project

Langkah-langkah membuat repository baru di GitHub dan menghubungkannya dengan project lokal di VS Code:

  1. Login ke akun GitHub (github.com).
  2. Klik tombol "New Repository" (atau ikon tanda tambah + di kanan atas).
  3. Beri nama repository: website-windah-basudara.
  4. Pilih opsi Public (agar bisa diaktifkan sebagai GitHub Pages).
  5. Jangan centang "Initialize with README" jika ingin mengunggah project dari folder komputer yang sudah ada.
  6. Klik Create repository.

Menghubungkan VS Code ke GitHub via Terminal:

VS Code Integrated Terminal (Bash)
# 1. Buka folder project di VS Code, lalu buka Integrated Terminal (Ctrl + ~) git init # 2. Hubungkan repository lokal dengan URL repository remote GitHub git remote add origin https://github.com/USERNAME_KAMU/website-windah-basudara.git # 3. Ubah nama branch utama menjadi 'main' git branch -M main

4. Proses Wajib: Add → Commit → Push

Siklus kerja wajib setiap kali ada perubahan kode pada Visual Studio Code:

Git Terminal Workflow
# LOKASI: Terminal VS Code # Langkah A: Menambahkan seluruh file/perubahan baru ke Staging Area git add . # Langkah B: Menyimpan snapshot perubahan beserta pesan deskriptif git commit -m "feat: membuat tampilan portofolio windah basudara dan dokumentasi tugas" # Langkah C: Mengunggah/Push commit dari komputer lokal ke server GitHub git push -u origin main

Tahap Edit & Push Kembali (Re-Push):

Ketika melakukan revisi atau penambahan foto baru di kemudian hari:

  1. Buka dan edit file di VS Code.
  2. Jalankan lagi perintah: git add .
  3. Jalankan commit baru: git commit -m "fix: memperbarui galeri foto dan soundboard"
  4. Jalankan push: git push

5. Proses Memublikasikan dengan GitHub Pages

Agar website dapat diakses oleh guru, teman, dan publik secara online:

  1. Buka repository website-windah-basudara di halaman GitHub web browser.
  2. Masuk ke tab menu Settings (ikon roda gigi di bagian atas).
  3. Pada sidebar sebelah kiri, cari dan klik menu Pages.
  4. Pada bagian Build and deployment -> Branch:
    • Ubah dropdown dari None menjadi main.
    • Biarkan folder tetap /(root).
  5. Klik tombol Save.
  6. Tunggu 1–3 menit hingga muncul banner hijau bertuliskan:
    Your site is live at https://USERNAME_KAMU.github.io/website-windah-basudara/

6. Penjelasan Konsep Push dan Pull

Pemahaman inti mengenai pertukaran file dalam Git Version Control System:

PUSH (Komputer → GitHub)

Definisi: Proses mengirimkan atau mengunggah commit history dan perubahan kode terbaru dari repository lokal (Komputer/VS Code) menuju ke remote repository (GitHub Server).

Perintah CLI: git push origin main

PULL (GitHub → Komputer)

Definisi: Proses mengambil dan menggabungkan (fetch + merge) perubahan kode terbaru dari remote repository (GitHub Server) ke repository lokal di komputer kita.

Perintah CLI: git pull origin main

7. Kendala, Cara Mengatasi, & Refleksi

Kendala yang Ditemukan Selama Pengerjaan Project:

  • Kendala 1: Gambar tidak muncul saat dipublikasikan di GitHub Pages.
    Solusi: Memastikan penulisan path relatif (misal assets/images/foto.jpg) sudah benar dan memperhatikan huruf besar/kecil (case-sensitive) pada nama file di Linux server GitHub.
  • Kendala 2: Error autentikasi saat melakukan git push (Personal Access Token required).
    Solusi: Membuat Personal Access Token (PAT) di setting akun GitHub atau melakukan login via VS Code GitHub Extension.
  • Kendala 3: Halaman GitHub Pages 404 Not Found.
    Solusi: Memastikan file utama bernama persis index.html (huruf kecil semua) dan diletakkan di root folder project.
